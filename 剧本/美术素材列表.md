

根据我们之前的剧情，整理了各个章节中可能需要的场景（背景）美术素材清单：

**【第一章：猝死】**

1.  **现代公寓卧室（主角房间）：**（bg_bedroom）
    *   **整体风格：** 略显凌乱但充满现代科技感的学生卧室。
    *   **关键元素：** 电脑桌（上面有多台显示器、键盘、鼠标、散乱的草稿纸、咖啡杯）、床铺（可能有些凌乱）、书架（堆满专业书籍和一些动漫周边）、窗户（窗外是深夜的城市或小区景象）。
    *   **氛围：** 凌晨，灯光主要来自电脑屏幕和台灯，整体色调偏冷，营造熬夜的疲惫感。
2.  **心电图监护仪界面（过场动画）：**（bg_hospital）
    *   **风格：** 科技、医疗感。
    *   **关键元素：** 显示心电波形的屏幕，波形从剧烈跳动到逐渐平缓最终变为直线，伴有相关数值显示。
    *   **氛围：** 紧张、冰冷、生命流逝的无力感。
3.  **时空漩涡（过场动画）：**
    *   **风格：** 玄幻、抽象、动态。
    *   **关键元素：** 色彩斑斓的光带交织、旋转形成的深邃隧道，给人强烈的视觉冲击和空间扭曲感。
    *   **氛围：** 神秘、未知、眩晕。

**【第二章：初醒】**

1.  **古代茅草屋内部（主角苏醒处）：**（bg_grasshouse）
    *   **整体风格：** 简陋、贫苦的古代农家/药童居所。
    *   **关键元素：** 茅草屋顶、粗糙的木梁（可挂干草药）、硬板床、破旧木柜、陶罐、墙角堆放的药草、简陋的门窗。
    *   **氛围：** 清晨，阳光透过缝隙洒入，略带尘埃感，古朴、宁静，但略显清贫。
2.  **古代小村庄场景（室外）：**（bg_village）
    *   **整体风格：** 唐代风格的乡村。
    *   **关键元素：** 几户茅草屋或夯土房、泥土小路、远处的田野或小山、村口的古树（可选）、一些简单的农具。
    *   **氛围：** 古朴、宁静、田园风光。
3.  **村头老者家（茅草屋内部，与主角家类似但可有细微差别）：**（bg_elderhouse）
    *   **整体风格：** 与主角家茅草屋类似，但可能更显病气或简陋。
    *   **关键元素：** 病床、简单的家具、药罐等。
    *   **氛围：** 略显昏暗，体现病人的虚弱。

**【第三章：院考】**

1.  **唐朝京城街道：**（bg_street）
    *   **整体风格：** 繁华、古朴的唐代都城街道。
    *   **关键元素：** 古代建筑（坊市、店铺、民居）、石板路、来往的行人（作为背景元素）、牌楼、旗幡等。
    *   **氛围：** 热闹、充满生活气息，体现古都的繁荣。
2.  **太医署大门及庭院：** （bg_taiyishu）
    *   **整体风格：** 官方机构，庄重、古朴，带有医学氛围。
    *   **关键元素：** 气派的门楼（上有“太医署”牌匾）、庭院（可能有药圃、石碑、回廊等）、进出的学子和医官。
    *   **氛围：** 严肃、庄重、书香与药香混合。
3.  **太医署考场（室内）：** （bg_examroom）
    *   **整体风格：** 宽敞、明亮的古代考场。
    *   **关键元素：** 考官席、考生坐席（书案、蒲团）、用于考核的药材、病人（用于面诊考核）。
    *   **氛围：** 紧张、肃穆。
4.  **太医署面诊隔间（室内）：** （bg_examine）
    *   **整体风格：** 相对独立、安静的诊疗空间。
    *   **关键元素：** 病床、简单的桌椅、屏风（可选）。
    *   **氛围：** 专注、略带压抑（因有病人）。

**【第四章：诡变】**

1.  **太医署御药房（夜晚 - 案发前）：** （bg_pharmacy）
    *   **整体风格：** 存放珍贵药材的官方库房，整齐、肃穆。
    *   **关键元素：** 高大的药柜（格子分明，可能贴有标签）、中央的桌案（可能有医书、油灯）、昏暗的光线（油灯照明）。
    *   **氛围：** 安静、略显阴森（夜晚）。
2.  **太医署御药房（夜晚 - 案发后）：** （bg_pharmacy_dead）
    *   **整体风格：** 同上，但增加了血腥和诡异元素。
    *   **关键元素：** 倒地的小吏尸体、地上的血迹、散落的物品（可选）、更加昏暗和摇曳的灯光。
    *   **氛围：** 惊悚、恐怖、不安。
3.  **药房窗外夜空（真龙托梦场景）：** （bg_nightsky）
    *   **整体风格：** 压抑、神秘。
    *   **关键元素：** 浓密的乌云、缝隙中透出的微弱月光、巨大的龙形阴影在云层中翻腾（可以是抽象的剪影或局部特写）。
    *   **氛围：** 威严、不祥、超自然。
    *   **场景变化提示：** 本章明确提到“夜间场景，亮度偏暗”。

**【第五章：灭世】**

1.  **皇宫深处丹房（外部环境，可选）：** （bg_danfang_outside）
    *   **整体风格：** 皇宫内一处偏僻但守卫森严的院落。
    *   **关键元素：** 高墙、紧闭的院门、巡逻的守卫（可选）、通往丹房的小径。
    *   **氛围：** 压抑、神秘、戒备森严。
2.  **丹房内部（正常状态）：** （bg_danfang_inside）
    *   **整体风格：** 充满神秘感和压抑感的炼丹场所。
    *   **关键元素：** 巨大的丹炉（燃烧着火焰）、排列整齐的药柜（可能存放更奇特的药材）、研磨药材的工具、弥漫的烟雾和药味。
    *   **氛围：** 闷热、昏暗、略带不祥。
3.  **丹房内部（环境异变状态）：** （bg_danfang_inside_change）
    *   **整体风格：** 在正常状态基础上增加诡异、邪恶的元素。
    *   **关键元素：**
        *   自动开合的药柜抽屉。
        *   药材上浮现的血色蒸汽。
        *   丹炉中燃烧的绿色火焰。
        *   扭曲拉长的影子。
    *   **氛围：** 恐怖、邪恶、超自然力量显现。

**【第六章：夜安】**

1.  **丹房内部（毒药炼成时）：** （bg_danfang_inside_poison）
    *   **整体风格：** 同第五章异变状态，但更为强烈。
    *   **关键元素：** 丹炉喷涌出浓郁的、带着甜腥味的红雾，雾气中闪烁幽光的颗粒。
    *   **氛围：** 极致的邪恶、毁灭气息。
2.  **皇都东南角落发射场（血色黎明）：** （bg_launchpad）
    *   **整体风格：** 开阔、荒凉，但有高科技（相对于古代）的发射装置。
    *   **关键元素：**
        *   两座高耸的火箭状发射装置。
        *   血色的天空（黎明）。
        *   远处的皇城轮廓（可选）。
    *   **氛围：** 末世感、悲壮、不祥。
3.  **火箭发射及空中爆炸场景（远景/特写）：** （bg_rocket_explosion）

4.  **丹房内部（结局演出 - 柜门弹开，药材化星河）：** （bg_danfang_inside_final）

    *   **关键元素：** 所有药柜柜门大开、无数药材（无论好坏）化为点点星光汇聚成璀璨星河、星河向上升腾融入天空。
    *   **氛围：** 神圣、净化、牺牲后的超脱与希望。
5.  **现代公寓卧室（结局 - 主角再次醒来）：** （bg_bedroom_final）
    *   **整体风格：** 与第一章类似，但光线明亮。
    *   **关键元素：** 电脑屏幕（动态壁纸上的奶龙微笑，切换到（bg_nailong））、窗外明媚的阳光。
    *   **氛围：** 平静、日常、略带恍惚（梦醒时分）。
